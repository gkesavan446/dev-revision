Prisma + PostgreSQL + Express + Neon — Build Checklist
1. Create the project
 Create an empty project folder
mkdir task-manager-prisma
cd task-manager-prisma
 Initialize Node
npm init -y
 Enable ES Modules in package.json
"type": "module"
 Install dependencies
npm install express cors dotenv @prisma/client@7.10.0
npm install @prisma/adapter-pg pg
npm install -D prisma@7.10.0 nodemon
 Add scripts
"scripts": {
  "dev": "nodemon server.js",
  "start": "node server.js"
}
2. Create PostgreSQL database
 Open pgAdmin
 Create database:
task_manager_prisma
 Keep PostgreSQL running
3. Initialize Prisma
 Run:
npx prisma init
 Confirm these files exist:
prisma/schema.prisma
prisma7.config.ts
.env
4. Configure local database
 Add PostgreSQL connection to .env
DATABASE_URL="postgresql://postgres:YOUR_PASSWORD@localhost:5432/task_manager_prisma"
 Never commit .env
5. Configure Prisma
 Update prisma7.config.ts
import "dotenv/config";
import { defineConfig } from "prisma/config";

export default defineConfig({
  schema: "prisma/schema.prisma",

  migrations: {
    path: "prisma/migrations",
  },

  datasource: {
    url: process.env["DATABASE_URL"],
  },
});
6. Create Prisma schema
 Open prisma/schema.prisma
 Add generator:
generator client {
  provider = "prisma-client"
  output   = "../generated/prisma"
  runtime  = "nodejs"
}
 Add PostgreSQL datasource:
datasource db {
  provider = "postgresql"
}
 Add User model:
model User {
  id        Int      @id @default(autoincrement())
  name      String   @db.VarChar(100)
  email     String   @unique @db.VarChar(255)
  createdAt DateTime @default(now()) @map("created_at")

  tasks Task[]

  @@map("users")
}
 Add Task model:
model Task {
  id          Int      @id @default(autoincrement())
  userId      Int      @map("user_id")
  title       String   @db.VarChar(255)
  description String?
  status      String   @default("pending") @db.VarChar(20)
  priority    String   @default("medium") @db.VarChar(20)
  createdAt   DateTime @default(now()) @map("created_at")
  updatedAt   DateTime @default(now()) @map("updated_at")

  user User @relation(fields: [userId], references: [id], onDelete: Cascade)

  @@map("tasks")
}
7. Validate and create database tables
 Validate schema
npx prisma validate
 Create migration
npx prisma migrate dev --name init
 Generate Prisma Client
npx prisma generate
 Confirm:
generated/prisma/

exists.

8. Create Prisma Client
 Create:
config/prisma.js
 Add:
import "dotenv/config";
import { PrismaPg } from "@prisma/adapter-pg";
import { PrismaClient } from "../generated/prisma/client.ts";

const adapter = new PrismaPg({
  connectionString: process.env.DATABASE_URL,
});

const prisma = new PrismaClient({
  adapter,
});

export default prisma;
9. Create Express server
app.js
 Create app.js
import express from "express";
import cors from "cors";

const app = express();

app.use(cors());
app.use(express.json());

app.get("/", (req, res) => {
  res.json({
    message: "Task Manager API with Prisma",
  });
});

export default app;
server.js
 Create server.js
import app from "./app.js";

const PORT = process.env.PORT || 5000;

app.listen(PORT, () => {
  console.log(`Server running on port ${PORT}`);
});
 Start:
npm run dev
 Test:
http://localhost:5000

26. Local ↔ Neon switching
Local
DATABASE_URL="postgresql://postgres:YOUR_PASSWORD@localhost:5432/task_manager_prisma"
DIRECT_URL="postgresql://postgres:YOUR_PASSWORD@localhost:5432/task_manager_prisma"
Neon
DATABASE_URL="NEON_POOLED_CONNECTION"
DIRECT_URL="NEON_DIRECT_CONNECTION"

Then restart the server.

Changing the URL does not require a migration if that database already has the required schema.

If the target database is empty:

npx prisma migrate deploy

Initialize

Create development migration

Apply existing migrations

Check migration status

Generate client

Push schema without migration history

Open Prisma Studio
