# Core React Recall

- JSX describes UI and accepts JavaScript expressions inside braces.
- Components are capitalized functions returning React elements.
- Props are read-only parent-to-child inputs.
- State is component memory; setters schedule rendering.
- Use functional setters when the next state depends on previous state.
- Pass event-handler functions; do not call them during render.
- Conditions can use `if`, ternary, logical AND, or early return.
- Render lists with `map` and use stable unique keys.
