# React Practice Questions

Attempt these without opening the completed components.

1. Build a searchable product list with an empty state.
2. Add a reusable `useDebounce` hook and show the applied query.
3. Build pagination with disabled boundary buttons.
4. Reset pagination to page one whenever a filter changes.
5. Render loading, error, empty, and success states for a request.
6. Add request cleanup with `AbortController` to a real fetch example.
7. Build `useLocalStorage` with a lazy initializer and functional updates.
8. Create a transaction form, validate it, normalize amount, and reset after success.
9. Explain which values should be state and which should be derived during render.
10. Explain where `useMemo` or `useCallback` would be unnecessary in these exercises.
