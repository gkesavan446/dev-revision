# React Revision

This section combines concise notes with one runnable Vite application.

## Structure

```text
03-react/
├── react-practice-app/
├── README.md
├── quick-recall.md
├── interview-questions.md
└── REACT-CHECKLIST.md
```

## Application modules

1. Core React — JSX, components, props, state, events, conditions, keys
2. Hooks — state, effects, refs, context, reducers and memo hooks
3. Forms — controlled fields, validation and submission
4. Rendering — lifecycle, reconciliation, batching and Strict Mode
5. Patterns — lifting state, composition, reusable components, custom hooks
6. Performance — memoization, referential equality, lazy and Suspense
7. Practice — search, debounce, pagination, fetch states and local storage

## Run

```bash
cd react-practice-app
npm run dev
```

## Final verification

```bash
npm run lint
npm run build
```

Study every topic by reading its source, interacting with the browser example, rebuilding it without looking, and explaining it aloud.
