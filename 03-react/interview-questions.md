# React Interview Questions

## Core questions

1. What problem does React solve?
2. What is JSX and how is it processed?
3. What is the difference between props and state?
4. Why should props not be mutated?
5. Why are keys required in lists?
6. Why can an array index be a poor key?
7. What causes a component to render?
8. Does every render update the DOM?
9. What is reconciliation?
10. What does lifting state mean?

## Hooks questions

11. What are the Rules of Hooks?
12. When should the functional state updater be used?
13. What problem does `useEffect` solve?
14. When does effect cleanup run?
15. What belongs in an effect dependency array?
16. How does `useRef` differ from state?
17. Context versus prop drilling: when is each appropriate?
18. When is `useReducer` preferable to `useState`?
19. How do `useMemo` and `useCallback` differ?
20. What is a custom hook?

## Rendering and performance

21. What are render and commit phases?
22. Why can Strict Mode show repeated development logs?
23. What is state batching?
24. What does `React.memo` compare?
25. How can inline objects or callbacks affect memoized children?
26. Why should memoization not be added everywhere?
27. What are lazy loading and code splitting?
28. What role does `Suspense` play with `lazy`?

## Practical questions

29. How do you build a controlled form?
30. How do you handle multiple fields with one handler?
31. How do you represent loading, error, empty and success states?
32. How do you prevent obsolete fetches from updating a component?
33. How would you implement debounced search?
34. How do you reset pagination after a filter changes?
35. How did you avoid state mutation in your projects?
36. Explain one React performance improvement you would measure first.

Answer each in 30–60 seconds and give one example from Trendz or Money Metrics.
