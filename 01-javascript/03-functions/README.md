# JavaScript Functions

This folder develops the function concepts commonly tested in JavaScript and MERN interviews.

## Learning order

1. Scope and lexical scope
2. Closures
3. Recursion
4. Callbacks
5. Higher-order functions
6. Currying
7. Pure and impure functions

## Revision method

Read the concept, predict the output, run the file, explain it aloud, and complete the practice task.

```bash
node 03-functions/01-scope.js
```

`this`, call, apply, bind, hoisting, execution context, and prototypes are covered later in Advanced Concepts.
