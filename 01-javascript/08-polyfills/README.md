# JavaScript Polyfills

These files recreate common behavior for interview practice. They are educational implementations, not replacements for native production methods.

## Learning order

1. `map`
2. `filter`
3. `reduce`
4. `forEach`
5. `call`
6. `apply`
7. `bind`
8. `Promise.all`
9. Debounce implementation

## Interview approach

Before coding, state:

- What the method returns
- Callback arguments
- Whether the source is mutated
- How empty and sparse arrays behave
- Which simplified edge cases your implementation does not cover
