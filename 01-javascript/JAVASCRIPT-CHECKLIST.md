## Weekly recall test

- [ ] Explain five random topics without opening notes.
- [ ] Solve two easy problems without help.
- [ ] Solve one intermediate problem without help.
- [ ] Predict one output question correctly.
- [ ] Write one polyfill or utility from memory.
- [ ] Connect two JavaScript concepts to a project.
- [ ] Update weak topics in the root `PROGRESS.md`.

## Completion standard

JavaScript revision is interview-ready when most core rows are green in understanding and explanation, while at least map/filter/reduce, closure, recursion, Promises, async/await, debounce, and one polyfill are green in coding.
