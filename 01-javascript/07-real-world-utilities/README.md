# Real-World JavaScript Utilities

These utilities combine closures, timers, higher-order functions, arrays, objects, and Promises.

## Learning order

1. Debounce
2. Throttle
3. Memoization
4. Grouping data
5. Flattening data
6. Validation helpers
7. Retry logic
8. Function composition

Run an example:

```bash
node 07-real-world-utilities/01-debounce.js
```

Do not only memorize these implementations. Trace the closed-over variables and explain when each utility is useful.
