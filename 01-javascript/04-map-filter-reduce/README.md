# Map, Filter and Reduce

These methods process arrays without manually managing loop indexes.

## Core idea

| Method | Purpose | Returns |
|---|---|---|
| `map` | Transform every item | New array with the same length |
| `filter` | Keep matching items | New array with zero or more items |
| `reduce` | Combine items into one result | Any accumulated value |
