# JavaScript Interview Questions

Use these questions for spoken recall after studying the topic files.

## Recommended method

1. Read only the question.
2. Answer aloud in 30–60 seconds.
3. Give one short example.
4. Compare with the reference answer.
5. Mark weak questions in `PROGRESS.md`.

## Files

- Fundamentals and collections
- Functions and advanced concepts
- Asynchronous JavaScript
- Output prediction
- Coding prompts
- Project-linked JavaScript questions

The answers are intentionally concise so they sound natural in an interview.
