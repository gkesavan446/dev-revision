# JavaScript Revision

Structured JavaScript notes, runnable examples, practice problems, polyfills, and interview questions.

## Learning order

| Order | Section | Focus |
|---|---|---|
| 1 | `01-fundamentals` | Variables, types, conversion, control flow, functions |
| 2 | `02-arrays-objects` | Collections, copying, destructuring, object utilities |
| 3 | `03-functions` | Scope, closure, recursion, callbacks, HOF, currying |
| 4 | `04-map-filter-reduce` | Transforming, selecting, aggregating data |
| 5 | `05-asynchronous-javascript` | Promises, async/await, event loop, fetch |
| 6 | `06-advanced-concepts` | `this`, prototypes, hoisting, execution context |
| 7 | `07-real-world-utilities` | Debounce, throttle, memoization, helpers |
| 8 | `08-polyfills` | Manual method implementations |
| 9 | `09-practice-problems` | Easy, intermediate, and advanced problems |
| 10 | `10-interview-questions` | Spoken recall, output questions, coding prompts |

## How to study a topic

1. Read **What**, **Why**, and the short interview answer.
2. Predict the examples before running them.
3. Run the file with Node.js.
4. Rewrite the main example without looking.
5. Complete the practice task.
6. Explain the topic aloud in under one minute.
7. Update `JAVASCRIPT-CHECKLIST.md` and the root `PROGRESS.md`.

## Running files

From this `01-javascript` folder:

```bash
node 03-functions/02-closure.js
node 05-asynchronous-javascript/06-event-loop.js
node 09-practice-problems/01-easy/solutions.js
```

## Revision levels

- Quick recall: read `quick-recall.md`
- Code recall: write the example or solve a practice problem
- Interview recall: answer questions aloud without notes

## Important rule

Do not mark a topic comfortable only because the example makes sense while reading. Mark it comfortable when you can explain and write it without help.
