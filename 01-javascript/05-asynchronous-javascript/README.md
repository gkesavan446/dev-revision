# Asynchronous JavaScript

This section explains how JavaScript handles delayed work without blocking the main thread.

## Learning order

1. Async basics and callback recap
2. Promises
3. Async/await
4. Async error handling
5. Promise methods
6. Event loop
7. Sequential and parallel execution
8. Fetch API
9. Practice questions
10. Solutions

Run files from the parent JavaScript folder:

```bash
node 05-asynchronous-javascript/02-promises.js
```

Some examples use short timers, so their output appears after a small delay.
