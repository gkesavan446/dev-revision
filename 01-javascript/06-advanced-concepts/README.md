# Advanced JavaScript Concepts

## Learning order

1. `this`
2. `call`, `apply`, and `bind`
3. Hoisting and the temporal dead zone
4. Execution context and call stack
5. Prototypes and inheritance
6. Classes
7. Event delegation
8. Memory and garbage collection

Run an example:

```bash
node 06-advanced-concepts/01-this-keyword.js
```

The event-delegation file contains browser code guarded from Node.js execution.
