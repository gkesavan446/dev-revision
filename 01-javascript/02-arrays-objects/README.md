# Arrays and Objects

This folder covers the JavaScript collections used most often in MERN applications.

## Learning order

1. Arrays
2. Array methods
3. Objects
4. Object methods
5. Destructuring
6. Spread and rest
7. Shallow and deep copy
8. Optional chaining and nullish coalescing

## How to revise

For each topic: read the explanation, predict the output, run the file, explain it aloud, and complete the practice task.

```bash
node 02-arrays-objects/01-arrays.js
```

Detailed `map`, `filter`, and `reduce` problems and polyfills belong in the separate `04-map-filter-reduce` section.
