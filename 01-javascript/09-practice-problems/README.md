# JavaScript Practice Problems

This section contains 21 interview-style problems based on the JavaScript topics already covered.

## Structure

```text
01-easy/          8 problems
02-intermediate/  8 problems
03-advanced/      5 problems
```

Each level has separate `questions.js` and `solutions.js` files.

## Practice method

1. Read one problem only.
2. Write examples and expected results.
3. Solve without looking at the solution.
4. Test normal, empty, and edge-case inputs.
5. Explain time and space complexity.
6. Compare your answer with the reference solution.

Do not memorize the reference code. A different clear and correct solution is valid.
