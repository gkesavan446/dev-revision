# JavaScript Fundamentals

This folder contains concise notes, runnable examples, interview answers, and practice tasks for the JavaScript fundamentals.

## Learning order

1. Variables
2. Data types
3. Type conversion
4. Operators
5. Conditionals
6. Loops
7. Function basics

## How to use each file

1. Read **What** and **Why**.
2. Predict each example's output.
3. Run the file with Node.js.
4. Explain the topic without reading the interview answer.
5. Complete the practice task at the bottom.

## Run an example

From the parent `01-javascript` directory:

```bash
node 01-fundamentals/01-variables.js
```

Or from this folder:

```bash
node 01-variables.js
```

## Completion rule

A topic is complete when you can:

- Explain it in simple words
- Predict the output of its examples
- Write a basic example without help
- Describe a common mistake
- Answer its interview questions
- Complete its practice task
